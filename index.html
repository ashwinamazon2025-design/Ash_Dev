Developers Page

New products are stored inside your GitHub repository under the products folder. The website reads that folder's manifest whenever it opens, so added product pages remain available after refresh and on other devices.

How this works: the browser does not keep your product pages only in local storage. When you press Create & Save Page, the product data is committed into your GitHub repository as products/product-name.json and the master list is stored in products/index.json.

GitHub Repository Connection

Use a fine-grained GitHub token restricted to this repository with Contents: Read and write. The token is kept only for the current browser session and is not written into this HTML file.

Repository Structure

After products are added, your repository will look like this:

index.html
videos/
  your-video-1.mp4
  your-video-2.mp4
products/
  index.json
  solar-rover-kit.json
  another-product.json

Upload video files normally to your GitHub videos folder. Then enter paths such as videos/solar-rover-1.mp4 in the product form.

Important GitHub setup

Create a fine-grained Personal Access Token in GitHub and give it access only to the repository containing this website.

Give the token Contents: Read and write permission. Do not paste the token directly into the HTML source.

Enter the token in the Developers tab only when you need to add or delete product pages.

Why the index.html does not need to be rewritten

The main index file automatically reads products/index.json. That file tells the website which product pages exist. When a product is added, the manifest is updated in GitHub, so the new tab/page appears automatically whenever the site is loaded.
