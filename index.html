Developer Console

Manage your public website from one place. Use the menu below to connect the repository, organize categories, edit products, update the Home carousel and manage pages.

Connect to Public Website Repository

The repository access token below is used only when saving files to GitHub and is kept in session storage.

Manage Product Categories

Add categories here and they will automatically appear in the Category drop-down below. Categories are saved in the public repository as content/product-categories.txt.

Manage Product Subcategories

Choose a parent category, then add or remove its subcategories. The Product Subcategory drop-down below changes automatically when a different Category is selected.

Create or Update a Product Page

Every new product saved here is automatically added to the public Home page as a product button. The public Amazon page automatically arranges all product buttons in a compact grid beside the carousel. As more products are added, the buttons, spacing and font sizes are reduced automatically so the area fits without a scrollbar.

Home Text Carousel

These messages appear in the small text carousel above the picture carousel on the public Home page.

Manage Product Pages

These projects are stored in the public website repository. The two main Home projects are also listed here and can be edited.

Target repository structure

The Developer Console will create and maintain:

content/
  home-text-carousel.json

products/
  index.json
  solar-rover-kit.json
  another-product.json

Video files

Upload videos separately into the videos/ folder of the public website repository. Then enter paths such as videos/project1.mp4.

GitHub Token Permission

Use a fine-grained token restricted to the public website repository with Contents: Read and write.
