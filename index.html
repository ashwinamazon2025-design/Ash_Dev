Supabase setup instructions

1. Create a free Supabase project.

2. In the SQL Editor, run the SQL below.

create table public.products (
  id bigint generated by default as identity primary key,
  name text not null unique,
  page_title text,
  category text,
  target_age text,
  description text,
  extra_notes text,
  layout text default 'grid',
  videos jsonb default '[]'::jsonb,
  created_at timestamptz default now()
);

alter table public.products enable row level security;

create policy "Public can read products"
on public.products
for select
using (true);

create policy "Authenticated users can add products"
on public.products
for insert
to authenticated
with check (true);

create policy "Authenticated users can update products"
on public.products
for update
to authenticated
using (true)
with check (true);

create policy "Authenticated users can delete products"
on public.products
for delete
to authenticated
using (true);

3. In Supabase Authentication, create your developer user with email and password.

4. Copy your Project URL and public anon key into the CONFIG section near the bottom of this index.html.

5. Upload this file as index.html to the root of your GitHub repository.
